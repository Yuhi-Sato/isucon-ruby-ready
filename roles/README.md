# 役割分担メモ

ISUCONの当日・練習時の役割分担を記録するディレクトリ。メンバーごとの担当・作業中のタスク・引き継ぎ事項をここにメモする。

## 読む順番

1. `README.md`（本ファイル）: ディレクトリの全体像と運用ルール
2. `initial-steps.md`: 競技開始直後の初動手順（担当者別のTODO）
3. `after-initial.md`: 初動完了後の役割（分析 → issue → PR → スコア確認のサイクル）
4. `roles.md`: 役割分担表とメンバー一覧
5. `tasks.md`: 改善タスクの担当・状況（競技中に随時更新する）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `README.md` | 本ファイル。運用ルールとディレクトリの説明 |
| `initial-steps.md` | 初動の手順とTODOリスト（担当者別） |
| `after-initial.md` | 初動以降の役割（分析→issue→PR→スコア確認のサイクル） |
| `roles.md` | 役割分担表（誰が何を担当するか） |
| `tasks.md` | 改善タスクの担当・状況の一覧 |

## 運用ルール

- 役割を変更したら、`roles.md`を更新してコミット・pushする
- 改善に着手する前に`tasks.md`へ担当者を書き、同じ箇所を複数人が触らないようにする
- 計測結果は`tmp/measure`に保存されるので、ここにはコピーせず、担当者が判断した内容のみを`tasks.md`に残す
