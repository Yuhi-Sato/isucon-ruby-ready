# 役割分担メモ

ISUCONの当日・練習時の役割分担を記録するディレクトリ。メンバーごとの担当・作業中のタスク・引き継ぎ事項をここにメモする。

## 読む順番

1. `README.md`（本ファイル）: ディレクトリの全体像と運用ルール
2. `initial-steps.md`: 競技開始直後の初動手順（担当者別のTODO）
3. `after-initial.md`: 初動完了後の役割（分析 → issue → PR → スコア確認のサイクル）
4. `roles.md`: 役割分担表とメンバー一覧
5. `skills.md`: メンバー別の必要スキル
6. `tasks.md`: 改善タスクの担当・状況（競技中に随時更新する）
