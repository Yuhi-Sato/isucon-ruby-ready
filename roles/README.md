# 役割分担メモ

ISUCONの当日・練習時の役割分担を記録するディレクトリ。メンバーごとの担当・作業中のタスク・引き継ぎ事項をここにメモする。

## 読む順番

1. `README.md`（本ファイル）: ディレクトリの全体像
2. `initial-steps.md`: 競技開始直後の初動手順（担当者別のTODO）
3. `after-initial.md`: 初動完了後の役割（分析 → issue → PR → スコア確認のサイクル）
4. `late-game.md`: 後半戦の役割（issueが尽きたらgarebareDAがCPUプロファイリング担当になる）
5. `skills.md`: メンバー別の必要スキル

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `README.md` | 本ファイル。ディレクトリの説明 |
| `initial-steps.md` | 初動の手順とTODOリスト（担当者別） |
| `after-initial.md` | 初動以降の役割（分析→issue→PR→スコア確認のサイクル） |
| `late-game.md` | 後半戦の役割（garebareDAが実装を離れてCPUのサンプルプロファイリングを担当） |
| `skills.md` | メンバー別の必要スキル |
