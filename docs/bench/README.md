# ベンチログ

このディレクトリには、ベンチマーカーの実行結果を保存します。

## 保存方法

ベンチを実行したブランチ・コミットを確認したうえで、結果を保存してください。

```bash
make save-bench-log < result.txt
```

保存ファイル名は次の形式です。

```text
YYYYMMDD-HHMMSS-<branch>-<commit>.md
```

GUIに表示された以下の情報を省略せず保存します。

- pass / fail / 失格
- 総合スコアと内訳
- エラー・警告・タイムアウト件数
- 満足度に関するヒント行
- 負荷レベル、ユーザー数、シナリオ到達状況
- 初期化時間とベンチマーカーのバージョン
